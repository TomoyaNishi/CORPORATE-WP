## 決まったこと

### 商品

| 項目 | 内容 |
|---|---|
| 単価 | 5ページ **15万円**（原稿支給）／ **20万円**（原稿込み）／ **25万円**（撮影込み） |
| 納期 | 原稿・写真が揃った日から **7営業日** |
| 保守 | 月 5,500円 ／ 11,000円（**ここが本命の収益**） |
| 目標 | 月4〜6件 = 月商60〜120万 |

**含まないものを見積書に必ず書く。** 特に「修正2回まで」。これがないと15万の案件が40時間案件になる。

### 営業先

**川越**（池袋から東武東上線急行で約30分・片道500円弱）

根拠:
- Web制作会社は東京3,765社／大阪1,059社／神奈川507社／愛知495社。埼玉は上位4県に入らず、競合密度が1桁低い
- 川越は観光地なので、飲食・甘味処・土産物店にとってHPが実際に売上の受け皿になっている
- 手持ちの和のデザイン資産（CORPORATE-WP）がそのまま小江戸の店に合う

第2波は所沢・朝霞・志木・ふじみ野。合わせて商圏人口110万。

### 判断基準

> **そのHPを今すぐ良くしたら、来月の売上に効く経路を1本、名前で言えるか。**

業種で切らない。「Webが売上の受け皿になっていない店」を落とす。

### 営業手法

**1通目は診断シートのみ。デモサイトは送らない。**

```
1通目  診断シート（写真なし・売り込みなし）
   ↓ 返信が来たら
2通目  「では、トップページ案を3日で作ります」
   ↓
商談
```

理由: 20件作って18件捨てる無駄が消える。何より **1件目で炎上しない**。
川越は狭いので「勝手にうちのサイト作って送ってきた」が1件広まると営業が全部死ぬ。

**写真は使わない。** ホットリンクは技術的には複製にあたらないが、
相手が感じるのは「俺の店の写真が知らない業者のサイトに出ている」であり、
法的な整理と感情は一致しない。プレースホルダーにする。

### ツール（すべて依存パッケージなし・Node 18+）

| ファイル | 役割 |
|---|---|
| `tools/collect.mjs` | Places APIで営業先を収集し、サイトからメールアドレスを抽出 |
| `tools/diagnose.mjs` | サイト自動診断（viewport / SSL / フォーム / 更新年 / 表示速度 / 画像URL） |
| `tools/template.mjs` | デモサイトと診断レポートのHTML生成（和食・美容室・整体の3テーマ） |
| `tools/build.mjs` | 一括生成・送付リスト・メール下書き・配信用CSV |
| `tools/preflight.mjs` | 送信ドメインの SPF / DKIM / DMARC / MX 確認 |

### 使い方

```bash
git clone https://github.com/TomoyaNishi/CORPORATE-WP.git
cd CORPORATE-WP
git checkout claude/homepage-sales-strategy-6tk006

# 差出人情報（住所は法令上必須）
cp data/sender.sample.json data/sender.json && vi data/sender.json

# 営業先を集める
export GOOGLE_PLACES_API_KEY=...
node tools/collect.mjs --area 川越市 --type 美容室 --type 整体 --limit 60
cp out/prospects.draft.json data/prospects.json   # 取捨選択する

# 生成
node tools/build.mjs --base https://kawagoe.pages.dev

# 送信前の確認
node tools/preflight.mjs nous-creators.com --selector google
```

配信サービス側に任せるほうが確実。`out/queue.csv` を取り込んで使う。

## 次にやること

1. **`data/sender.json` の住所を埋める**（1分・法令上必須）
2. **Places APIキーを取得して `tools/collect.mjs` を実行**（30分）
   - 無料枠で足りる
3. 出てきた候補を取捨選択して20件に絞る
4. `node tools/build.mjs` で診断シートを生成
5. Cloudflare Pages にデプロイ（`npx wrangler pages deploy dist`）
6. `out/queue.csv` を配信サービスに取り込んで送信開始

### 送信ペース（守ること）

| 日 | 通数 |
|---|---|
| 1〜3日目 | 10通/日 |
| 4〜7日目 | 20通/日 |
| 2週目以降 | 30〜40通/日 |

**バウンス率が5%を超えたら即停止。** リストの質が悪い証拠で、続けるとドメインが焼ける。

### 逆算

4件受注するには 300〜400通必要（返信率3〜5%、返信からの受注率40〜50%）。
ウォームアップ込みで **3週間かかる**。今日始めないと今月中は間に合わない。
