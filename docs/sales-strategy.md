# 5ページ15万・1週間納品モデル ── 商品設計と営業

対象: 株式会社秀 / NOUS
目的: 今すぐキャッシュを作る。回転で稼ぐ量産モデルを設計する

---

## 0. 前提の確定

| 項目 | 数値 |
|---|---|
| 単価 | 5ページ **15〜20万円** |
| 納期 | **7営業日以内** |
| 相手 | 従業員1〜10人・社長が決裁者 |
| 目標 | 月4〜6件 = **月商60〜120万** |

---

## 1. 前回の判断を訂正する

前回「美容室・飲食は単価が合わない」と書いたが、あれは **50万以上の案件を前提にした計算** だった。
15〜20万・1週間納品というモデルでは、結論が逆になる。

| 論点 | 50万モデル | **15万モデル（今回）** |
|---|---|---|
| 何を売るか | 成果が出るHP | **体裁・信用・検索で出てくること** |
| 決裁 | 相見積り・稟議 → 数ヶ月 | **社長の即決レンジ** |
| 必要な母数 | 年数件でいい | **月4〜6件＝母数が要る** |
| 最適な相手 | 蔵元・食品製造 | **美容室・飲食・整体・工務店・士業** |

15万は「見積りを取って比較する」金額ではなく、**「その場で決める」金額** である。
ここが最大の違いであり、営業のやり方そのものが変わる。

> **20万の"名刺"は成立する。50万の"成果を出すHP"は成立しない。**
> 価格帯が変われば、売っている価値そのものが変わる。

なお蔵元・食品製造は「悪い」のではなく、**決裁に時間がかかるので今すぐの金には向かない**。
キャッシュが回り始めてからの高単価枠として残す（後述の2階建て）。

---

## 2. 差別化は「速度」と「明快さ」だけでいい

美容室・飲食にWeb業者の営業が毎日届いているのは事実。
ただし、その全員がこう言っている。

- 見積りは「ヒアリングしてからのご提案」
- 納期は「2〜3ヶ月」
- 金額は「30万〜」（＝いくらか分からない）

対してこちらは **「5ページ・15万円・1週間」** と最初の1行で言い切れる。
業界標準が曖昧なので、**明快さそのものが差別化になる**。ここで勝負する。

---

## 3. パッケージ設計

### 価格3段

| プラン | 価格 | 内容 |
|---|---|---|
| **ライト** | **15万** | 原稿・写真を支給いただく |
| **スタンダード** | **20万** | ヒアリングから原稿構成・ライティングまで込み |
| **撮影付き** | **25万** | 半日の撮影込み（店舗・スタッフ・商品） |

※ 迷ったらスタンダードを勧める。原稿が来ないことが納期崩壊の最大要因（後述）。

### 含むもの（5ページ）

1. トップ
2. サービス／商品（メニュー）
3. 会社概要／店舗情報
4. よくある質問 or お客様の声
5. お問い合わせ

- WordPress（**自分たちで更新できる**）
- スマホ対応
- お問い合わせフォーム
- SSL設定
- Googleビジネスプロフィールとの連携
- **修正2回まで**
- 公開後30日のサポート

### 含まないもの ── ここを書かないと必ず赤字になる

| 項目 | 追加費用 |
|---|---|
| 6ページ目以降 | 1ページ +2.5万 |
| 3回目以降の修正 | 1回 +1.5万 |
| ロゴ制作 | +5万 |
| 写真撮影（ライト／スタンダード） | +5万 |
| EC機能 | 別見積り |
| 多言語対応 | 別見積り |
| 予約システム連携 | 別見積り |

**「修正2回まで」を書かないと、15万の案件が40時間案件になる。** ここが利益の生死を分ける。

### 条件（見積書に必ず明記）

- **着手金50%**（7.5〜10万）。入金確認後に着手
- 納期は **原稿・写真が全て揃った日から7営業日**
- 原稿が揃わない間は納期を起算しない

## 4. 本命は保守費

制作費は一度きり。**事業を安定させるのは月額のほう。**

| プラン | 月額 | 内容 |
|---|---|---|
| ベーシック | **5,500円** | サーバー・ドメイン管理、バックアップ、月1回の軽微修正 |
| 運用込み | **11,000円** | 上記＋更新代行 月2回（お知らせ・メニュー変更など） |

- 20件契約 = **月11〜22万の固定収入**
- 原価はサーバー月1,000円前後＋ドメイン年1,500円前後。粗利率は高い
- 制作時に **必ずセットで提案する**。後から売るのは難しい

小規模店舗ほど「自分で更新する」と言って結局しない。
更新代行は、売り込むまでもなく必要とされている。

---

## 5. 工数の現実（1件あたり）

| 工程 | 時間 |
|---|---|
| ヒアリング | 1h |
| 構成・ワイヤー | 2h |
| デザイン調整（型からの差し替え） | 3h |
| 実装 | 8h |
| 原稿整理 | 3h |
| 修正2回 | 3h |
| 公開・各種設定 | 2h |
| **合計** | **約22時間** |

- 15万 ÷ 22時間 = **時給 約6,800円**。成立する
- 月4件 = 88時間。営業と並行しても回る

### ただしこれは「型」がある場合の数字

型がなければ1件40〜60時間かかり、時給は3,000円を割る。**そこで事業が止まる。**

CORPORATE-WP の資産（`assets/css/` のレイヤー構成、`components/` の分割、
`--c-indigo` / `--c-gold` / `--c-vermilion` のトークン、`fade-up`）は、
そのまま量産テーマの土台になる。**着手前にこれを1本仕上げる。**

## 6. 営業先

### セグメント（回転重視）

美容室 / 飲食店 / 整体・接骨院 / ネイル・まつげ / パーソナルジム /
工務店・リフォーム / 士業（税理士・行政書士・社労士）/ 教室・スクール

### 条件

- 従業員 1〜10人
- **社長・オーナーが決裁者**（15万を即決できる）
- HPが古い、スマホで崩れる、または無い
- Googleビジネスプロフィールは埋まっている（＝ネットに関心はある）

### 前回との違い

前回は「Webが売上の受け皿になっているか」で切ったが、
それは **50万を回収する必要があるとき** の基準。

15万なら、相手が買うのは成果ではなく **体裁・信用・検索で出てくること**。
名刺代わりのHP、採用のためのHP、取引先に見せるためのHP ── これは正当な需要である。
**受け皿テストは、20万を超えるプランを提案するときだけ使う。**

---

## 7. 営業のやり方

### 先出し無料制作は、全社にはやらない

計算するとすぐ分かる。

- 1件の試作に2〜3時間 × 10社 = 25時間
- 受注率10%なら1件（15万）。営業25時間＋制作22時間 = **時給3,200円**

**この価格帯では、先出し無料制作は営業工数が制作工数を食う。**

### 修正版のフロー

| 段階 | やること | 工数 |
|---|---|---|
| 1 | パッケージを明示したメールを送る（試作なし） | 5分/社 |
| 2 | 返信が来た相手にだけ「3日でトップページだけ作ります」 | 2〜3h |
| 3 | 試作を見せて商談。着手金50%を受け取る | 1h |

**無駄玉が消える。** 型ができて1件30〜45分で試作が作れるようになったら、
段階1から試作を付けてもいい。それまではこの順番で回す。

### メール文面

```
件名: ホームページ、5ページ15万円・1週間で作ります

◯◯様

株式会社秀の西と申します。

　・ご自身で更新できます（WordPress）
　・スマートフォン対応、お問い合わせフォーム、SSLまで込み
　・修正2回まで込み
　・原稿と写真をご用意いただければ、7営業日で公開できます

◯◯様のサイトを拝見して、スマートフォンで見たときに
文字が小さく読みづらいのが気になりました。
（※必ず1社ずつ具体的に書く。テンプレのままは送らない）

金額と納期は上記で固定です。追加費用は事前に全て提示します。

もしご興味があれば、先に◯◯様向けのトップページを1枚だけ
3日ほどでお作りします（無料・ご依頼の義務はありません）。
実物を見てからご判断いただくのが早いと思います。
```

**送信者名・住所・配信停止先・拒否できる旨** の記載は特定電子メール法上の義務。

## 8. 2階建てにする

| | 今の主軸 | 後から足す |
|---|---|---|
| 商品 | 5ページ15〜20万・1週間 | 蔵元・食品製造への50万以上の案件 |
| 相手 | 美容室・飲食・整体・工務店・士業 | 茨城の老舗食品／醸造 |
| 稼ぎ方 | **回転数**（月4〜6件）＋保守の積み上げ | 単価と紹介の連鎖 |
| いつ | 今すぐ | キャッシュが回り始めてから |

先出し無料制作（蔵元向け）は捨てない。ただし **週末に1件ずつ**。
今月の金は、上の量産モデルで作る。

## 9. 着手順

1. **量産テーマの「型」を1本仕上げる** ← これが全ての前提。ここを飛ばすと破綻する
2. 見積書・パッケージ表を1枚のPDFにする（含む／含まない／条件）
3. 保守プランの契約書ひな形を用意する
4. リスト30社（上記セグメント・条件）
5. 送信 → 返信が来た相手にだけ試作

**着手金50%を取れない相手は受けない。** 今すぐ金が要るなら、
「受注した」ではなく「入金された」だけを見る。
