# HP制作 × 新規開拓 戦略メモ

対象: 株式会社秀 / NOUS
目的: 知名度ゼロの状態から、HPが弱い企業へ「先に作って見せる」営業で最初の受注を取る

---

## 0. 前提

- LPではなく **ホームページ（回遊・更新・検索流入を持つ複数ページ構成）** を作る
- 営業メール送付時に、その会社向けの試作サイトを一時公開したURLを添える
- 実績・知名度はまだない。使える武器は「既存2社の事例」と「作れる速度」だけ

### 既存実績の性質（重要）

既存2件は、セッション名の通り **「だるま食品 LP制作」「来福酒造LP」= どちらもLP** である。

- 業界・地域は揃っている（茨城の老舗食品・醸造）。これは強い
- ただし **HPの実績は今のところゼロ**。LPの実績は、そのままではHP案件の証明にならない
- 老舗が知りたいのは「かっこいいページを作れるか」ではなく
  **「自分たちで更新して運用し続けられるか」**。LPはそれに答えていない

つまり、この2件は「業界での信用」にはなるが「HPを任せる根拠」にはまだ足りない。
その穴を埋めるのが、次項以降で繰り返し出てくる **「型」** である。
型そのものが、HPの実績代わりになる。

---

## 1. 最初に潰すべき矛盾

NOUSのサイトは、こう名乗っている。

- トップ: 「売りたい施策はありません。」
- 実績: 「ホームページを作らず、広告から直したケース」
- About: 「ちゃんと考えて ちゃんと断る」

この会社が **頼まれていないHPを作って送りつける** と、思想と手法が正面から矛盾する。
しかも矛盾に気づくのは、いちばん取りたい相手（自分で考えている経営者）である。

### 対策：送るのは「完成したHP」ではなく「診断の結論としての試作」

順番を、こう固定する。

1. 現状サイトの何が機会損失になっているか（事実だけ）
2. だから、直すならこの順番だという判断
3. その判断を目に見える形にしたものが、この試作です

この順番なら、NOUSの「順番を設計する」という主張とそのまま一致する。
逆順（試作を先に見せて「作りました、どうですか」）にした瞬間、
他の制作会社の営業メールと区別がつかなくなる。

## 2. 「無料で作って送る」の実務リスク

やる価値はある。ただし、以下3点を外すと事故になる。

### (a) 著作権

| 使ってよい | 使ってはいけない |
|---|---|
| 社名・所在地・事業内容などの事実情報 | 公式サイト / Googleマップ / 食べログ等の写真 |
| 自分で撮影した写真 | ロゴマーク（図形部分） |
| ライセンスの明確なフリー素材（「イメージ」と明記） | 商品パッケージ画像、パンフレットのコピー文 |

- 社名を **テキストで組む** のは問題ない。ロゴを再現・トレースするのはNG。
- 写真は全てフリー素材＋キャプションに「※写真はイメージです」を固定で入れる。
- 老舗ほど写真とロゴを大事にしている。ここを雑にやると、それだけで終わる。

### (b) 特定電子メール法

法人・団体が **サイト上で公開している** アドレス宛の広告メールは、原則オプトイン不要（法の例外規定）。
ただし本文への以下の記載は義務。テンプレのフッターに固定で入れる。

- 送信者の氏名・名称
- 住所
- 受信拒否の通知を受けるURLまたはメールアドレス
- 受信拒否ができる旨

※ 個人事業主の個人アドレス、問い合わせフォーム経由の送信はグレー。避ける。

### (c) 試作サイトの公開設定（必須）

- `noindex, nofollow` を必ず入れる（相手の本サイトと検索で競合させない）
- URLは推測不能なものにする（Basic認証があればなお良い）
- **公開期限を切る**（例：14日）。期限があること自体をメールに書く
- フッターに「これは株式会社秀が作成した提案用の試作です。◯◯様の公式サイトではありません」を明記

## 3. 「無料」が価格を殺す問題

最初から完成品を無料で渡すと、「タダで作れる人」として記憶される。
紹介されるときも「無料で作ってくれるらしい」と伝わる。これは中長期で効いてくる。

### 対策

- 無料なのは **提案（試作トップ1枚）** であって、制作ではない、と線を引く
- 「通常◯◯万円の初期設計フェーズを、今回は先に形にしています」と価格を先に置く
- 「7日間の限定公開」など、期限で希少性を担保する
- 全ページ作らない。**トップ1枚＋下層はワイヤーのみ**。
  全部作ると「もう完成している＝勝手にやられた」という感情が先に立つ

## 4. 数の現実

勝手に作って送る営業は、1件の工数が重い。楽観的な数字を置かない。

- 送付 10〜20件 → 返信 1〜3件 → 商談 1件 程度を健全な見込みとする
- 返信ゼロの週は普通にある
- 続かない最大の理由は「1件に時間がかかりすぎる」こと

### だから、先に「型」を1本作る

CORPORATE-WP の資産（和紙テクスチャ、縦書き、`--c-indigo` / `--c-gold` / `--c-vermilion`、
`fade-up`、`components/cta-consult.php`）は、そのまま **老舗・醸造・食品向けテーマの型** になる。

型ができれば、1社あたり差し替えるのは以下だけ。

- キャッチコピー（2〜3行）
- 会社の物語（創業年・製法・つくり手）
- 商品3〜6点の名前と説明
- 写真（フリー素材から6枚選ぶ）
- アクセントカラー1色

これで **1社 2〜3時間** に落とす。ここに到達しない限り、この戦略は継続できない。

## 5. 営業先の決定

### 原則

知名度ゼロの状態で唯一効くのは **「同業の事例」** である。
分散させた瞬間に、唯一の武器を失う。

### 第1波セグメント

**茨城・北関東の老舗食品製造／醸造業**（酒蔵・味噌・醤油・酢・納豆・漬物）

- 既存2社と同業なので、事例がそのまま効く
- 業界の言葉（仕込み、蔵、杜氏、直販、蔵元直送）が通じる
- 訪問できる距離。返信後の商談の強さが違う
- 全国の日本酒蔵元は約1,500場。味噌・醤油等を含めれば数千社。母数は十分

### 絞り込み条件（3つ以上該当したらリスト入り）

1. スマホで見て崩れる／文字が極端に小さい
2. お知らせ・更新が2年以上止まっている
3. https（SSL）未対応
4. 自社ECがない、または楽天/Amazonのみで自社導線がない
5. **直販をやっている**（蔵元直送・直営店・ふるさと納税）＝Webが売上に直結する
6. 社長・専務が取材やSNSで発信している＝意思決定者を特定できる

条件5と6は特に重視する。Webを直せば数字が動く会社であり、かつ話が通る相手がいる会社だから。

### 避けるべき先

| 避ける | 理由 |
|---|---|
| 歯科・整体・美容室・エステ | Web業者の営業が飽和。1日に何通も来ている |
| 上場・準大手 | 意思決定者にメールが届かない |
| **HPが存在しない会社** | 「無い」のは意思決定の結果。必要性を感じていない |

もっとも動くのは **「ある。でも古い」** 会社である。

### 第1波は10社

20社ではなく10社。理由は、返信が来なかったときに
「文面が悪いのか、リストが悪いのか」を切り分けられる粒度がこのサイズだから。

## 6. 進め方

| 週 | やること | 完了条件 |
|---|---|---|
| 週0 | 老舗向けテーマの「型」を1本仕上げる | 別会社の情報を入れて2時間で1本できる |
| 週1 | リスト10社作成 | 1社ごとに「なぜこの会社か」を1行で書けている |
| 週2 | 10社分の制作 | 診断1枚＋トップ1枚（下層はワイヤーのみ） |
| 週3 | 送信 | 送信後、返信ゼロなら文面ではなく**リストの条件**を疑う |

返信が来たら、いきなり試作の説明をしない。
まず現状をヒアリングし、NOUSの本題（順番の話）に戻す。
試作は、その会話の結論を裏付ける材料として最後に置く。

## 7. LP と HP の作り分け（実装差分）

LPの手順のままHPを作ると失敗する。押さえる差分は以下。

- **情報設計を先に決める**
  トップ / 商品一覧・詳細 / 蔵・つくり手（物語）/ 会社概要 / お知らせ / お問い合わせ
- **お知らせを投稿タイプで運用可能にする**
  老舗ほど「自分たちで更新できるのか」を気にする。ここは提案の核になる
- **構造化データ**（Organization / LocalBusiness / Product）と OGP
- **既存ドメイン・URLの移行計画**
  必ず論点になる。提案時点で1行触れておくだけで、他社と明確に差がつく
- 回遊設計（商品 → 物語 → 問い合わせ）。LPの縦一本とは別の考え方

## 8. メール文面の原則

- **件名にHP制作と書かない**（書いた瞬間に他の営業メールと同じ棚に入る）
- 1通目で売り込まない。事実の指摘だけで止める
- 「勝手に作りました」と正直に書く。隠すと不信になる
- **相手の商品を実際に買って、飲んで／食べて、その1文を入れる**。返信率を一番動かすのはここ
- 締めは「不要でしたらこのまま削除します。ご返信いただければ即日公開を停止します」

### 文面ドラフト

```
件名: 御社サイトの、スマートフォンでの表示について

株式会社◯◯
◯◯様

突然のご連絡失礼いたします。株式会社秀の西と申します。

先日、◯◯（商品名）を取り寄せて飲みました。
（※ここは必ず具体的に。買っていないなら送らない）

その流れで御社サイトを拝見したのですが、
スマートフォンで見たときに文字が小さく、
商品ページから購入までの導線が途中で切れているように見えました。

御社の商品と、蔵の話の伝わり方に対して、
サイト側が追いついていないのが、単純にもったいないと感じました。

弊社は普段、「作るべきかどうか」から一緒に考える仕事をしています。
なので今回も、まず何を直すべきかを整理したうえで、
その結論を目に見える形にした試作をお作りしました。

　https://example.com/xxxx （14日間の限定公開・検索には出ません）

※これは弊社が作成した提案用の試作であり、御社の公式サイトではありません。
※写真はすべてフリー素材です。ロゴ・商品画像は使用しておりません。

見ていただいたうえで「今は必要ない」というご判断でしたら、
それはそれで正しい判断だと思います。
その旨ご返信いただければ、即日公開を停止いたします。

もし少しでも引っかかる点があれば、
15分ほどお時間をいただき、現状を伺えればと思います。

---
株式会社秀　西 智也
（住所）
配信停止・公開停止のご連絡: nishi@nous-creators.com
```

## 9. まず着手すべき1つ

リスト作りでもメール文面でもなく、**「型」を1本仕上げること**。

型がないまま10社分を手作りすると、3社目で止まる。
型があれば、リストもメールもあとから何度でも回せる。
